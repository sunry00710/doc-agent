| 场景 | 用哪节 | 关键差异 |

## 三、环境变量（唯一权威清单）

`.env.example` 是全量清单与注释；生产必改四项：

| 变量 | 为什么 |
|---|---|
| `ENVIRONMENT=production` | 触发 JWT 密钥强制校验（保护） |
| `JWT_SECRET` | 默认值只许 dev/test |
| `DATABASE_URL` | 绝对路径，放数据目录 |
| `MODEL_PROVIDER` | 不设默认 fake（离线演示），接了真模型必须显式设置 |

# Doc Agent 演示版使用指引

## 登录

打开 `http://127.0.0.1:5173/`，使用演示账号登录：

- 用户名：`demo`
- 密码：`DemoPass-2026!`

此账号仅用于本地演示，部署到共享环境前必须替换密码或删除。

## 推荐体验路径

1. **工作台**：输入“请检查当前文档”，查看 Agent 的离线演示回复。输入“提交文档”或“申请晋升”等变更请求时，会先要求确认。
2. **文档**：在左侧选择“演示项目：年度审计报告”，再选择“2026 年上半年审计整改报告”和版本 `v1`。可查看正文、评审、写作契约和版本对比入口。
3. **知识库**：搜索“采购比价”或“整改建议”，查看已索引的演示文档片段。
4. **引用**：Agent 返回引用时，可在右侧“引用”区域打开来源片段。

## 演示数据

演示数据为公开合成内容，包含审计范围、主要发现和整改建议。可重复执行以下命令以补齐缺失的演示对象，不会重复创建已有项目、文档版本或知识索引：

```bash
PYTHONPATH=. .venv/Scripts/python.exe scripts/seed_demo.py
```

## 当前限制

- Agent 使用本地 FakeProvider，只用于演示，不会调用真实模型。
- 演示数据包含项目、文档、版本和共享知识库；复杂的评审、返修、批准、晋升流程仍需通过已有 API 或进一步补充 UI 操作。
- 本地 SQLite、开发 JWT 密钥和演示账号不适用于生产环境。
